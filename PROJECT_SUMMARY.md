## 🚀 Quick Start

### 1. Installation (2 minutes)

```bash
# Navigate to project
cd excel-insight-generator

# Run startup script (Windows)
run_app.bat

# Or manually:
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configuration (1 minute)

Edit `.env` file:
```bash
OPENAI_API_KEY=your_key_here
GEMINI_API_KEY=your_key_here
```

### 3. Launch (30 seconds)

```bash
streamlit run app.py
```

### 4. Analyze (2 minutes)

1. Upload Excel file
2. Click "Analyze Data"
3. Review insights
4. Download report

**Total time from setup to insights: ~5 minutes**
